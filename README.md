# Olá, tudo bem? 👋

Desenvolvedor focado em **automação e sistemas back-end para operações logísticas**, com experiência construindo aplicações full-stack quando o problema pede interface própria. Gosto de pegar processos manuais e transformar em software confiável.

## 🛠️ Stack

- **Backend:** Python (FastAPI, Flask), PostgreSQL, Redis, APScheduler
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Infra:** Docker, integrações de API (Gmail API, OAuth), WebSockets

## 🚀 Projetos em destaque

### Ops Hub
Portal interno de operações para empresas de logística/3PL: dashboards operacionais, gestão de RH (ponto, treinamentos, avaliações de competência), fluxo de aprovações e automação de extração de relatórios de um sistema WMS.
`FastAPI` · `Flask` · `React + TypeScript` · `PostgreSQL` · `Redis`
Destaque técnico: controle de acesso por níveis de visibilidade e permissão, cobrindo múltiplos módulos de um mesmo sistema.

### Inbound Scheduler
Ferramenta de coordenação de recebimento e devolução de mercadorias: lê e-mails via Gmail API, extrai dados estruturados de threads não estruturadas e organiza o agendamento de recebimentos e devoluções.
`FastAPI` · `React + TypeScript` · `PostgreSQL` · `Gmail API` · `WebSockets`
Destaque técnico: sessões criptografadas, sanitização contra XSS e suíte de testes cobrindo permissões de acesso por thread.

### Zapin
MVP de rede social + mensageria em tempo real voltado a comunidades e vendas: feed, curtidas, follows, mensagens diretas e notificações.
`FastAPI` · `React + TypeScript` · `WebSockets`
Destaque técnico: autenticação sem senha via código enviado por e-mail e canal de conversa em tempo real via WebSocket.
